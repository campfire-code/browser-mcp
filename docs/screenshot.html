浏览器助手（MCP）

让 Claude Code、Cursor、VS Code 等 AI 助手直接操作浏览器：打开网页、点击、填表、读取内容。需要 Node.js 18 或更新版本。

配置示例（写进客户端的 MCP 配置）

{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}

Claude Code 一行命令

claude mcp add playwright npx @playwright/mcp@latest
安全提示　它能替 AI 操作你的浏览器，不要在登录了重要账号的浏览器里随意使用；加 --isolated 可使用不保留登录状态的临时环境。
